# Financial Securities Decision System

**Maturity: Active engineering / validation.**
**No trading bot. No buy/sell automation. No alpha claim. No investment advice. Research / engineering validation only.**

**Problem addressed:** What has changed for a given security, and whether that change affects the investment judgment already made about it.

**Judgment supported:**

```text
Evidence → State → Horizon → Transmission → Judgment
```

A single real-world event can simultaneously change fundamental reality, market information, time horizon, valuation assumptions, risk, and optionality. The system is built to keep these distinguishable rather than collapsing them into a single "bullish / bearish" label.

**Public-safe engineering evidence:** historical fixtures exist internally for testing this evidence/state/horizon structure. No fixture file or test-run output is linked from this repository — their existence is disclosed as a description, not demonstrated here. In any case, their output would not be a performance or returns claim.

**What you can use this for:**

- Evaluate how a real-world event changes an investment thesis — without letting a regional or product-specific fact bleed into the whole picture
- Decompose a bond or credit instrument's price move into its separate real causes (issuer credit, market-wide liquidity, risk-free rate, sector shock)
- Determine how one company's default affects different claims on it differently

**What you actually get:** evidence intake with sourcing discipline, state tracking per company or security, time-horizon awareness, explicit cause-and-effect linking, a hard separation between business judgment and market reaction, and selective, auditable reassessment. See the [Public Case Library](../../cases/library/) — [Nvidia, 2025](../../cases/library/nvidia-selective-reassessment.md) and [Boeing and Hertz](../../cases/library/financial-credit-event-decomposition.md) — for real, re-verified cases.
