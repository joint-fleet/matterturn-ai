# How we work

**Decision first, system second.** Every system starts from a real decision question a professional has to answer, not from a technology we want to showcase.

**Private by default, public by exception.** Core judgment engines, case evidence, and internal governance live in private repositories. Content moves to this public hub only when it is deliberately prepared for public release — never by default, never by copying a private repo's internal framing.

**Status is stated, not implied.** Every system and every claim here carries an explicit status (verified / prototype / planned). We'd rather under-claim and be right than imply more maturity than exists.

**Competitions are scoped before they start.** Public competition work (see [`competitions/`](../competitions/)) is split up front into "existing foundation" and "new build-lab work," so the increment built during the event is auditable in Git history rather than mixed in with pre-existing capability.

**Human review before client work.** Nothing described in this repository is a substitute for expert review. Systems are described as producing reviewable judgments and reports, not as replacing the professionals who sign off on them.
